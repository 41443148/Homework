## 解題說明

這道題目的核心概念是集合的冪集（Powerset），要求寫出一個遞歸函數來計算所有可能的子集。

### 解題策略

1. 問題定義與數學原理冪集定義：若 $S$ 是一個包含 $n$ 個元素的集合，則 $S$ 的冪集為所有可能子集構成的集合。若集合大小為 $n$，其總子集數量會是 $2^n$ 個（包含空集合與集合本身）。

核心思維（二選一法）：對於集合中的每一個元素，我們都有兩種選擇：

(1. ) 不放入當前子集。

(2. ) 放入當前子集。透過遞歸完整走訪這兩種選擇，就能不重複、不遺漏地產生所有子集。

2.遞歸設計邏輯（演算法步驟）這是一個經典的回溯/遞歸設計，主要包含兩個條件：遞歸終止條件（Base Case）：
當我們考慮完集合中的每一個元素（即索引 index 等於集合大小 n）時，代表已經決定好一個完整的子集，此時即可直接輸出或儲存該子集。   
遞歸推進與分支（Recursive Step）：針對當前索引的元素 S[index]：

(1. )分支一（不選）：直接進入下一個元素的遞歸 index + 1，當前子集內容不變。

(2. )分支二（選）：將 S[index] 加入當前子集中，然後進入下一個元素的遞歸 index + 1；在遞歸返回後，將該元素移除（回溯），以便乾淨地進行下一個分支。

## 程式實作

以下為主要程式碼：

```cpp
#include <iostream>

using namespace std;

void generateSubsets(const char S[], int n, int index, char current[], int currentSize) {
    if (index == n) {
        cout << "(";
        for (int i = 0; i < currentSize; ++i) {
            cout << current[i];
            if (i + 1 < currentSize) {
                cout << ",";
            }
        }
        cout << "), ";
        return;
    }

    generateSubsets(S, n, index + 1, current, currentSize);

    current[currentSize] = S[index];
    generateSubsets(S, n, index + 1, current, currentSize + 1);
}

int main() {
    char S[] = {'a', 'b', 'c'};
    int n = 3;

  
    char current[3];

    cout << "powerset(S) = { ";
    generateSubsets(S, n, 0, current, 0);
    cout << "}" << endl;

    return 0;
}
```

## 效能分析

1. 時間複雜度： $O(2^n \cdot n)$ 。若集合 $S$ 含有 $n$ 個元素，其冪集總共包含 $2^n$ 個子集。由於每個子集在輸出或建構時需要花費 $O(n)$ 的時間來處理元素，因此整體時間呈指數級成長。
2. 空間複雜度： $O(n)$ 。空間開銷主要取決於遞迴呼叫堆疊（Call Stack）的最大深度以及暫存當前子集的陣列大小，兩者最大深度皆為 $n$，在一般輸入規模下極具效率且記憶體開銷低。

### 非遞迴的結論

遞迴設計的直覺性與核心思想
在本程式中，計算冪集採用遞迴的主要原因在於其「二元選擇（選或不選）」的遞迴樹結構。針對集合中的每一個元素，程式皆能明確分支為「不包含當前元素」與「包含當前元素」兩種狀態。這種寫法能夠完美對應數學上的定義式，邏輯簡單、直覺且易於編寫與驗證，特別適合用來展現回溯法（Backtracking）的核心思想。

限制突破與狀態管理由於作業或環境限制僅允許使用 <iostream>，程式無法直接使用 <vector> 等動態容器。因此，開發時透過傳入固定大小的暫存陣列與記錄當前大小（currentSize），在遞迴返回時手動進行狀態恢復。這種設計不僅符規，還能將遞迴深度嚴格控制在 $O(n)$ 內，兼顧了效能、記憶體安全與程式碼的簡潔性。
